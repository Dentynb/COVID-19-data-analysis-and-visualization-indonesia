# 🦠 COVID-19 Data Analysis & Visualization – Indonesia

## 📌 Overview

This project analyzes and visualizes COVID-19 data across provinces in Indonesia using **Power BI**. The interactive dashboard presents key COVID-19 indicators, including total cases, deaths, recoveries, active cases, and new cases over time.

The dashboard combines geographical, temporal, and province-level visualizations to explore the distribution and development of COVID-19 conditions across Indonesia.

---

## 🎯 Objectives

- Analyze COVID-19 conditions across provinces in Indonesia.
- Explore the distribution of active cases across regions.
- Compare COVID-19 cases, deaths, and recoveries between provinces.
- Observe the development of new cases, deaths, and recoveries over time.
- Present COVID-19 data through interactive visualizations for easier data exploration.

---

## 📊 Dashboard Features

### 🔢 Key COVID-19 Indicators

The dashboard provides an overview of:

- **Total Cases**
- **Total Deaths**
- **Total Recovered**

These indicators provide a summary of the overall COVID-19 conditions represented in the dataset.

### 🗺️ Active Cases by Province

A geographical map visualizes the distribution of **Total Active Cases** across provinces in Indonesia, allowing users to explore regional differences.

### 🥧 Deaths by Province

A pie chart presents the **Average Total Deaths by Province**, showing the distribution of deaths across different provinces.

### 📈 COVID-19 Trends Over Time

A line chart visualizes:

- New Cases
- New Deaths
- New Recovered

The visualization allows users to explore changes in COVID-19 conditions across **quarter, month, and day**.

### 📊 Province-Level Comparison

A bar chart compares **Total Recovered** and **Total Deaths** across provinces, making it easier to observe differences between regions.

### 🔎 Province Filter

An interactive **Province** filter allows users to focus the dashboard analysis on a specific province.

## 📈 Visualization Approach

The dashboard uses multiple visualization techniques to explore different aspects of the data:

- **Cards** for key COVID-19 indicators
- **Map** for geographical distribution of active cases
- **Pie Chart** for the distribution of average deaths by province
- **Line Chart** for changes in new cases, deaths, and recoveries over time
- **Bar Chart** for province-level comparisons
- **Interactive Filter** for province-specific exploration
